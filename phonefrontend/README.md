# כובי לטלפון (React Native, Expo)

גרסה לטלפון של מסך העובד. הגרסה הראשית נשארת האתר ב-`frontend/`, ומסך הנציג נשאר רק באתר (`/rep`).
השרת לא משתנה: האפליקציה פונה לאותו API ומקבלת את אותם אירועים (SSE), כרטיסים ותשובות נציג.

## הפעלה

```bash
cd phonefrontend
npm install
cp .env.example .env      # ממלאים EXPO_PUBLIC_API_URL
npx expo start            # סורקים את הקוד ב-Expo Go בטלפון
```

- **מול השרת ב-Render:** `EXPO_PUBLIC_API_URL=https://<השרת>.onrender.com`.
- **מול שרת מקומי:** בטלפון `localhost` הוא הטלפון עצמו. ממלאים את כתובת המחשב ברשת (למשל `http://192.168.1.20:8000`), ומפעילים את השרת עם `--host 0.0.0.0`.
- אחרי שינוי ב-`.env` מפעילים מחדש את `npx expo start`.

## בדיקות

```bash
npm test
```

Jest עם `jest-expo` ו-Testing Library, עם שרת מזויף. כל הבדיקות ב-`tests/`, באותן תיקיות כמו בקוד (`tests/components/`, `tests/employee/`, `tests/lib/`...), והן מייבאות את הקוד כ-`@/...` (`moduleNameMapper` ב-`package.json`). `tests/setup.js` רץ לפני כל קובץ. הכרטיסים נבדקים על כרטיסים אמיתיים מהשרת (`tests/fixtures/`, עותק של אלה שב-`frontend/tests/fixtures/`).

**זמן:** בהרצה הראשונה, כשהמטמון של Jest ריק, בדיקה אחת ב-`tests/employee/screens.test.js` עוברת את 5 השניות ונכשלת. בהרצה שנייה כל ה-23 עוברות. כך היה גם לפני ההעברה ל-`tests/`.

## מה שונה מהאתר

| נושא | אתר | טלפון |
|---|---|---|
| פריסה | שיחה וכרטיס זה לצד זה | שתי לשוניות: "שיחה" ו"השוואה". הלשונית מראה את השינוי בנטו, ונקודה כתומה כשיש השוואה חדשה |
| כניסה | `sessionStorage`, נמחק עם סגירת הלשונית | בזיכרון בלבד, נמחק עם סגירת האפליקציה |
| תשובת נציג כשהמסך פתוח | צפצוף ו-"(1)" בכותרת | רטט |
| חזרה למסך | `visibilitychange` | `AppState` (האפליקציה חוזרת לחזית) |
| זרם התשובה | `fetch` של הדפדפן | `fetch` של Expo, שקורא את הגוף תוך כדי זרימה |
| זרם האירועים | `EventSource` | `react-native-sse` |
| Markdown | `react-markdown` | `react-native-markdown-display`, עם אותם חסמים: בלי טבלאות, HTML, קישורים, תמונות |
| כיוון | `dir="rtl"` | `direction: 'rtl'` על השורש, בלי קשר לשפת הטלפון |

הלוגיקה זהה לאתר: פענוח ה-SSE (`src/lib/sse.js`) הועתק כמו שהוא, ו-`api.js` ו-`EmployeeScreen.js` שומרים על אותם כללים (המסד הוא מקור האמת, תשובת נציג מחשבת מחדש פעם אחת, וכל מספר מגיע מהשרת).
